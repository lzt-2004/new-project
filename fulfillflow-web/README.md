# FulfillFlow Web

> FulfillFlow 的 Vue 3 管理台，用于联调库存和订单 API。当前刻意限定在后端已经提供的接口范围内，不扩展为完整商城或权限后台。

## 当前功能

- 创建 SKU 与初始库存
- 按 SKU ID 查询库存
- 补货可售库存
- 创建订单并展示订单价格快照
- 确认待支付订单
- 取消待支付订单
- 显示本次浏览器会话中操作过的订单
- 显示接口请求日志：请求方法、路径、HTTP 状态与后端消息
- 检测后端健康状态

## 前置条件

- Node.js 20 或更高版本
- FulfillFlow 后端已启动在 `http://localhost:8081`

## 开发启动

Windows PowerShell：

```powershell
cd D:\project-zz\fulfillflow\fulfillflow-web
npm.cmd install
npm.cmd run dev
```

打开 `http://localhost:5173`。

Vite（前端开发构建工具）会将 `/api` 和 `/actuator` 请求代理到后端 `8081` 端口，因此本地开发不需要先在后端额外配置 CORS（跨域访问）。

## 生产构建

```powershell
npm.cmd run build
```

构建产物输出到 `dist/`，该目录不会提交。后续部署时由 Nginx 提供静态文件服务。

## 手工联调路径

1. 创建一个初始库存为 `5` 的 SKU。
2. 查询创建后返回的 SKU ID，确认可售库存为 `5`。
3. 创建数量为 `3` 的订单，确认可售库存变为 `2`，预占库存变为 `3`。
4. 确认支付该订单，确认订单状态变为 `PAID`（已支付），可售库存仍为 `2`，预占库存仍为 `3`。
5. 尝试取消已支付订单，确认请求返回冲突，库存不会变化。
6. 新建另一笔待支付订单后取消，确认可售库存恢复，预占库存释放。
7. 再次取消同一订单，确认订单状态保持 `CANCELLED`（已取消），库存不会再次变化。

## 当前边界

前端仅在浏览器会话内保存已操作订单，后端暂未提供订单列表和分页查询接口。待后端补齐订单查询 API 后，再增加列表、筛选与详情页面。
